# Matriz

## Objetivo

Este projeto consiste em criar um sistema que permite ao usuário gerenciar uma lista de imóveis. O sistema oferece as seguintes funcionalidades: salvar um imóvel, visualizar o primeiro imóvel adicionado e sair do programa.

## Funcionalidades

1. **Salvar um imóvel**: O usuário pode adicionar informações sobre um imóvel, incluindo o nome do proprietário, número de quartos, número de banheiros e se possui garagem.
2. **Visualizar imóveis**: O usuário pode visualizar o primeiro imóvel adicionado à lista. Após visualizar, o imóvel é removido da lista.
3. **Sair do programa**: O usuário pode encerrar o sistema ao escolher essa opção.

## Tecnologias utilizadas

- HTML5
- JavaScript
- Prompt para entrada de dados
- Alert para mensagens de sucesso e erro
- Switch para lidar com as opções do usuário

## Como executar

Para executar o projeto, siga os passos abaixo:

1. Clone o repositório para o seu computador.
2. Abra o arquivo `index.html` no navegador.

## Conceitos de programação presentes

- **Estrutura de controle**: do, for, if, switch
- **Manipulação de arrays**: push, shift
- **Entrada de dados**: prompt
- **Saída de dados**: alert
- **Conversão de tipos**: parseInt
- **Variáveis e tipos de dados**: let, const, boolean
- **Conceito de pilha de dados**: O sistema usa uma pilha para gerenciar a ordem dos imóveis adicionados, onde o último imóvel adicionado é o primeiro a ser visualizado.
